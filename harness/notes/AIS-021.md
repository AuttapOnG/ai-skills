# AIS-021 — figma-to-html skill

**Status:** done (2026-07-23)

## What shipped
[`skills/figma-to-html/SKILL.md`](../../skills/figma-to-html/SKILL.md) — drive the Figma REST
API to produce either faithful static HTML or a token-light design brief for codegen.

## Origin & IP hygiene
Concept from an external Claude-specific skill whose core was a bundled ~1,200-line Python
exporter. **No text or code reused** — the script's logic was distilled to an API/mapping
playbook (endpoints, node→CSS rules, rate-limit discipline, fidelity-bug classes) and
rewritten. Deliberately genericized: the original hardcoded a proprietary brand-font map —
ours describes the pattern ("brand font → self-host or open-font fallback") with a license
warning and no brand names. Grep sweep for org markers: clean.

## Key decisions
- **Markdown-only compliance:** the registry forbids *bundled* executables; the skill instead
  teaches the agent to write its own glue code at run time. The mapping table (atomic
  graphics, LINE→div, border-overlay, textAutoResize branch, horizontal-only clipping) is the
  distilled value — that survives any implementation language.
- Two modes with the brief mode listed first — for codegen a compact brief beats faithful
  HTML and is far cheaper; ties into the registry's token-thrift posture.
- Verification section keeps the "compare against Figma's own /v1/images render at 2× DPI"
  ground-truth rule.
