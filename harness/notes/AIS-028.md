# AIS-028 — commit skill: no redundant message confirmation

**Status:** done locally (2026-08-27; pending push)

## Goal

Treat an explicit user request to commit as authorization to create the commit,
instead of asking the user to approve an AI-derived commit message a second time.

## Acceptance criteria

- The skill commits without redundant message confirmation after an explicit
  commit request.
- It still asks when a material choice remains unresolved: ambiguous file scope,
  missing required ticket ID, atomic grouping, or a failed verification gate.
- A user-supplied exact message is preserved unless it violates a required repo
  convention.
- Completion reports the commit hash, final message, and committed file scope.
- Registry generation and repository validation pass.

## What changed

- Replaced the unconditional message-review prompt with explicit-request
  authorization.
- Preserved prompts for unresolved material choices and exact user messages.
- Added post-commit reporting requirements for hash, message, and file scope.
- Regenerated `registry.json` from the updated frontmatter.
